Introduction

WebSearch Agent est un agent de recherche web IA avec function-calling. Il detecte l'intention, selectionne les outils, et retourne des reponses structurees avec citations.

En resume

13 sources de recherche, 10 modeles LLM, authentification OAuth2, rate limiting par client, panneau d'administration complet.

Features

  • Recherche intelligente — Routage automatique par intention et domaine
  • 13 sources — Perplexity, Tavily, Brave, DuckDuckGo, Wikipedia, GitHub, News, etc.
  • 10 modeles LLM — Selection aleatoire ponderee, fallback automatique
  • OAuth2 JWT — Scopes (read/write/admin), refresh token
  • Rate limiting — Configurable par client
  • Admin panel — Dashboard, logs live, metrics, settings

Architecture

Client → FastAPI → Auth + Scope + Rate Limit
  → Agent IA (routeur → LLM → tools → synthese)
    → 13 sources (parallele)
  → Reponse avec citations

OAuth2 Setup

Configurer l'authentification OAuth2 pour vos applications.

1. Creer un client

Via l'admin panel : Apps → Ajouter une app

2. Obtenir un token

curl -X POST http://localhost:4500/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "votre-client-id",
    "client_secret": "votre-client-secret"
  }'

3. Utiliser le token

curl -H "Authorization: Bearer eyJ..." \
  http://localhost:4500/chat \
  -d '{"message": "test"}'

4. Refresh token

curl -X POST http://localhost:4500/oauth/token/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token": "eyJ..."}'
Expiration

Les tokens expirent apres 1 heure. Utilisez le refresh endpoint pour en obtenir un nouveau. Le refresh fonctionne pendant 15 minutes apres l'expiration.

Classe OAuth2

import requests

class WebSearchClient:
    def __init__(self, client_id, client_secret):
        self.client_id = client_id
        self.client_secret = client_secret
        self.token = None

    def login(self):
        resp = requests.post(
            'http://localhost:4500/oauth/token',
            json={
                'client_id': self.client_id,
                'client_secret': self.client_secret
            }
        )
        self.token = resp.json()['access_token']

    def search(self, query):
        return requests.post(
            'http://localhost:4500/chat',
            json={'message': query},
            headers={'Authorization': f'Bearer {self.token}'}
        ).json()

# Utilisation
client = WebSearchClient('id', 'secret')
client.login()
result = client.search('python')
print(result['response'])

Script OAuth2 complet

#!/bin/bash
TOKEN=$(curl -s -X POST http://localhost:4500/oauth/token \
  -H "Content-Type: application/json" \
  -d '{"client_id":"...","client_secret":"..."}' | jq -r '.access_token')

curl -s -X POST http://localhost:4500/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"message": "test"}' | jq -r '.response'
JavaScript FAQ

FAQ

Questions frequentes.

Combien de temps pour une reponse ?

3-8 secondes selon la complexite. Cache hit : 0ms.

Quels modeles LLM sont supportes ?

10 modeles via OpenRouter : Llama, Qwen, DeepSeek, Mistral, etc.

Comment augmenter le rate limit ?

Via Admin → Apps → Modifier le rate limit du client.

Les tokens expirent-ils ?

Oui, apres 1 heure. Utilisez le refresh endpoint.

Comment activer le 2FA ?

Admin → Settings → Security → Activer 2FA
