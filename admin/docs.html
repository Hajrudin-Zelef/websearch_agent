Pourquoi WebSearch Agent ?

Les moteurs de recherche classiques retournent des liens. Les LLM seuls sont limites a leur date d'entrainement. WebSearch Agent combine les deux : il cherche en temps reel, analyse les sources, et synthetise une reponse complete avec citations.

❌ LLM classique
  • Pas d'acces a l'information en temps reel
  • Connaissances datees (cutoff d'entrainement)
  • Pas de sources, pas de citations
  • Hallucinations possibles
✅ WebSearch Agent
  • Recherche en temps reel via 13 sources
  • Informations a jour et verifiees
  • Citations avec URLs sources
  • Verification croisee des donnees

Comment ca marche

Le flux complet en 5 etapes :

1. Requete
Question en naturel
2. Routage
Detection intention + complexite
3. Recherche
Execution parallele des outils
4. Synthese
LLM analyse et resume
5. Reponse
Texte + citations sources

Features principales

Recherche intelligente

Routage automatique par intention, domaine et complexite. Selection optimale des sources.

Execution parallele

Jusqu'a 6 outils executes en parallele. Cache LRU pour les requetes frequentes.

Securite enterprise

OAuth2 JWT, scopes, rate limiting, 2FA, headers de securite. Pret pour la production.

Observabilite totale

Metrics en temps reel, logs structures, circuit breaker, monitoring par source.

Authentication & OAuth2

3 modes d'authentification supportes. OAuth2 recommande pour la production.

Vue d'ensemble

🔑 API Key

Simple et rapide. Pas de token a gerer.

✓ Aucune configuration
✗ Pas de scopes
✗ Pas de refresh

Recommande. Scopes, refresh, expiration.

✓ Scopes (read/write/admin)
✓ Refresh token

Development uniquement.

✓ Aucune config
✗ Rate limit strict (IP)
✗ Pas de tracking

Grace period

Le refresh fonctionne pendant 15 minutes apres l'expiration du token. Pass ce delai, il faut se re-authentifier.

async function apiCall(url, options) {
  const response = await fetch(url, options);
  if (!response.ok) {
    const error = await response.json();

Endpoints Rate Limiting

Rate Limiting

Protection contre les abus — sliding window de 60 secondes.

Comment ca marche

Fenetre glissante de 60s. Chaque requete est comptee, les anciennes expirent automatiquement.

0s15s30s45s60s
← Fenetre glissante — les anciennes requetes expirent →

Limites

TypeLimiteConfigurable
Par client (API key/JWT)30 req/min (defaut)Oui via admin
Par IP (sans credentials)30 req/minNon
Configuration

Modifier le quota par client via Admin → Apps ou l'API :

curl -X PUT http://localhost:4500/admin/clients/{id}/rate-limit \
  -H "Content-Type: application/json" \
  -d '{"rate_limit": 100}'

Headers de reponse

HeaderDescriptionExemple
X-RateLimit-LimitLimite maximale30
X-RateLimit-RemainingRequetes restantes25

Gestion du 429

1. Exponential Backoff

Attendre 1s, puis 2s, puis 4s...

2. Attendre 60s

Reessayer apres la fenetre

3. Augmenter la limite

Via admin pour les clients

Exemple avec retry

async function fetchWithRetry(url, options, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    const response = await fetch(url, options);
    if (response.status !== 429) return response;
    const delay = Math.pow(2, i) * 1000;
    await new Promise(r => setTimeout(r, delay));
  }
  throw new Error('Max retries exceeded');
}

Classe WebSearchClient

Client complet avec OAuth2, refresh automatique, et gestion d'erreurs.

import requests

class WebSearchClient:
    """Client WebSearch Agent avec OAuth2 automatique."""

    def __init__(self, base_url, client_id, client_secret):
        self.base_url = base_url
        self.client_id = client_id
        self.client_secret = client_secret
        self.token = None

    def login(self):
        """Obtenir un access token."""
        resp = requests.post(
            f'{self.base_url}/oauth/token',
            json={
                'client_id': self.client_id,
                'client_secret': self.client_secret
            }
        )
        resp.raise_for_status()
        data = resp.json()
        self.token = data['access_token']
        return data

    def _headers(self):
        return {'Authorization': f'Bearer {self.token}'}

    def search(self, message, thread_id=None):
        """Envoyer une recherche."""
        payload = {'message': message}
        if thread_id:
            payload['thread_id'] = thread_id

        resp = requests.post(
            f'{self.base_url}/chat',
            json=payload,
            headers=self._headers()
        )
        resp.raise_for_status()
        return resp.json()

    def list_threads(self):
        """Lister les threads."""
        resp = requests.get(
            f'{self.base_url}/threads',
            headers=self._headers()
        )
        return resp.json()

    def health(self):
        """Verifier le serveur."""
        return requests.get(f'{self.base_url}/health').json()


# Utilisation
client = WebSearchClient('http://localhost:4500', 'id', 'secret')
client.login()

# Premiere question
result = client.search('Qu\'est-ce que le W3C ?')
print(result['response'])
thread_id = result['thread_id']

# Follow-up
result = client.search('Et ses standards ?', thread_id=thread_id)
print(result['response'])

def refresh_token(client):
    """Rafraichir le token automatiquement."""
    resp = requests.post(
        f'{client.base_url}/oauth/token/refresh',
        json={'refresh_token': client.token}
    )
    if resp.status_code == 200:
        client.token = resp.json()['access_token']
        return True
    return False

Gestion des erreurs

import requests

def safe_search(client, message):
    """Recherche avec gestion d'erreurs."""
    try:
        result = client.search(message)
        return result
    except requests.exceptions.HTTPError as e:
        if e.response.status_code == 401:
            # Token expire — re-login
            client.login()
            return client.search(message)
        elif e.response.status_code == 429:
            # Rate limit — attendre
            import time
            time.sleep(60)
            return client.search(message)
        else:
            raise

class WebSearchClient {
  constructor(baseUrl, clientId, clientSecret) {
    this.baseUrl = baseUrl;
    this.clientId = clientId;
    this.clientSecret = clientSecret;
    this.token = null;
  }

  async login() {
    const resp = await fetch(`${this.baseUrl}/oauth/token`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        client_id: this.clientId,
        client_secret: this.clientSecret
      })
    });
    const data = await resp.json();
    this.token = data.access_token;
    return data;
  }

  async search(message, threadId = null) {
    const body = { message };
    if (threadId) body.thread_id = threadId;

    const resp = await fetch(`${this.baseUrl}/chat`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.token}`
      },
      body: JSON.stringify(body)
    });
    return resp.json();
  }

  async listThreads() {
    const resp = await fetch(`${this.baseUrl}/threads`, {
      headers: { 'Authorization': `Bearer ${this.token}` }
    });
    return resp.json();
  }
}

Exemple React

import { useState } from 'react';

function ChatBot() {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');

  const sendMessage = async () => {
    if (!input.trim()) return;

    // Ajouter le message user
    setMessages(prev => [...prev, { role: 'user', content: input }]);

    const response = await fetch('http://localhost:4500/chat', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      },
      body: JSON.stringify({ message: input })
    });

    const data = await response.json();

    // Ajouter la reponse
    setMessages(prev => [...prev, {
      role: 'assistant',
      content: data.response
    }]);

    setInput('');
  };

  return (
    <div>
      {messages.map((msg, i) => (
        <div key={i} className={msg.role}>
          {msg.content}
        </div>
      ))}
      <input value={input} onChange={e => setInput(e.target.value)} />
      <button onClick={sendMessage}>Envoyer</button>
    </div>
  );
}

#!/bin/bash

# Configuration
BASE_URL="http://localhost:4500"
CLIENT_ID="votre-client-id"
CLIENT_SECRET="votre-client-secret"

# 1. Obtenir un token
TOKEN=$(curl -s -X POST "$BASE_URL/oauth/token" \
  -H "Content-Type: application/json" \
  -d "{\"client_id\":\"$CLIENT_ID\",\"client_secret\":\"$CLIENT_SECRET\"}" \
  | jq -r '.access_token')

echo "Token obtenu: ${TOKEN:0:20}..."

# 2. Recherche
RESULT=$(curl -s -X POST "$BASE_URL/chat" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"message": "Bonjour"}')

echo "Reponse: $(echo $RESULT | jq -r '.response')"
echo "Thread: $(echo $RESULT | jq -r '.thread_id')"

# 3. Refresh token
NEW_TOKEN=$(curl -s -X POST "$BASE_URL/oauth/token/refresh" \
  -H "Content-Type: application/json" \
  -d "{\"refresh_token\": \"$TOKEN\"}" \
  | jq -r '.access_token')

echo "Nouveau token: ${NEW_TOKEN:0:20}..."

#!/bin/bash

# Verifier la sante du serveur toutes les 60 secondes
while true; do
  STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:4500/health)
  TIMESTAMP=$(date +"%Y-%m-%d %H:%M:%S")

  if [ "$STATUS" = "200" ]; then
    echo "[$TIMESTAMP] OK"
  else
    echo "[$TIMESTAMP] ERREUR: $STATUS"
  fi

  sleep 60
done
